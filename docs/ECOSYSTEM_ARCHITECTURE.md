# AIAS Ecosystem Architecture

## Layer model

`Client → AIAS Advisory → Reach → Zeo → Settler`

- **Client** defines outcomes, constraints, and governance obligations.
- **AIAS Advisory** translates constraints into executable architecture decisions.
- **Reach** supports demand shaping and qualification strategy.
- **Zeo** executes platform and automation implementation.
- **Settler** operationalizes deployment, handoff, and repeatable governance.

## Automation lifecycle

1. Strategy
2. Design
3. Build
4. Automate
5. Govern
6. Scale

## Determinism and intelligence

Deterministic layers own policy, validation, and execution contracts.
Intelligence layers provide recommendations and optimization proposals within controlled boundaries.

## Deployment models

- **Self-hosted**: Full client infrastructure control.
- **Managed**: AIAS-managed operating model.
- **Federated**: Shared operations across entities with policy inheritance.

## Governance principles

- Policy before execution.
- Human review for high-risk transitions.
- Replayable logs and explainable decisions.
- Explicit non-fit criteria.
