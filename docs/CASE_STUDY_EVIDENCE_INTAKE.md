# Case Study Evidence Intake

Use this checklist before changing a scenario from `representative` to `client-approved`.

## Required record

- Written client approval and the approving role
- Sanitized problem statement and architecture boundary
- Measurement window, baseline, target, and calculation method
- Primary evidence sources such as signed acceptance records, run logs, or approved reports
- Known confounders, exclusions, and unresolved risks
- Approval date and a scheduled review date

## Publication rule

Numeric results must be reproducible from attributable evidence. Store confidential source material outside this public repository and record only a safe source label here. If evidence expires, is withdrawn, or cannot be reproduced, return the study to `representative` immediately.
